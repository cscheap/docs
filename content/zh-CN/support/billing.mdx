## 点数或订阅没有显示

确认登录的是购买账号，检查订单已完成而非待付款，并核对订阅起止日期。排队中的未来时段尚未生效。比较控制台与 `GET /me` 前，留出同步时间。

## 已付款但订单仍等待

检查付款单、网络、金额与支付状态。部分付款可能使订单保持待付款。适用时通过原订单继续支付，不要认为从支付页面返回就代表最终确认。取消订单不会自动退回已入账的钱包资金。

## API 费用与预期不同

检查请求时订阅是否有效、是否返回 `200`、批量原始长度，以及导出是否使用 `If-None-Match`。`402` 与 `429` 不同，不应通过立即重试解决。

求助时提供订单编号或请求 ID、UTC 时间和脱敏状态。不要提供钱包助记词、私钥或 API 凭证。

## 官方费率表

使用[获取费率](/docs/api/reference/markets/get-fees)读取市场已发布的费率表。它为每种用途提供一个槽位：`deposit`（买入）、`sale`（出售）与 `withdraw`（提现）。每个已发布的槽位都带有完整展开的官方计算链。绑定到链 `0` 的槽位明确表示无费用；槽位为 `null` 表示费率未知或该用途不受支持，绝不表示免费。读取费率表不需要 API 密钥。

cs.cheap 每条价格报价中的费后金额（`buy_amount`、`sale_amount`、`payout_amount`）以及 CSCP 估值，都使用这些官方计算链。详见[成本计算](/docs/concepts/cost-calculation)。

## 计算链与版本

计算链是有序的步骤列表。费用算子按比例乘除（`mul`、`div`），或以指定币种加减固定金额（`add`、`sub`）。换汇算子改变币种：按两种货币相对美元的参考汇率换算（`auto`），或按固定 `rate` 换算。换汇组在同一对货币之间执行多个换汇，取成功结果中的最小值、最大值或平均值。步骤的顺序和币种都很重要，简单相加百分比一般不能代替逐步应用计算链。金额为十进制数，每一步之后四舍五入保留八位小数。

每次保存修改都会产生新版本，早先的版本仍可读取。绑定固定指向某一个版本，因此修改链不会改变任何市场用途，直到绑定新版本为止。计算链不能删除。废弃不可撤销，只要还有绑定在使用该链，废弃就会被拒绝；已废弃的链仍可读取，也可以复制。

## 自己的费率链

你可以保留自己的费用算子、货币与计算链，并为自己把某条链绑定到市场用途：在控制台使用[市场费率](/docs/dashboard/market-fees)，或按[用 API 自定义费率](/docs/guides/customize-fees)通过 API 操作。保存需要有效订阅，读取不需要。你的记录默认私有，共享之后其他用户才能引用或复制。

费率工作区会为每种用途说明对你生效的链：你有自己的绑定且订阅有效时用你的，否则用官方的，再否则没有。绑定若因链已废弃或所用对象缺失而无法生效，会如实显示为不可用，绝不会被官方链悄悄替代。

自己的链只改变费率工作区和试算中的结果，绝不改变 API 的价格报价：`buy_amount`、`sale_amount`、`payout_amount` 与 CSCP 估值始终使用官方费率。

## 正确使用范围

这些定义用于数据处理与估算。市场实际结算、账号等级或支付方式可能影响交易。请读取当前费率表，不要把本指南中的费用说明硬编码为固定值。

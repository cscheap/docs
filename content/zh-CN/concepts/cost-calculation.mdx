## 三种不同金额

处理链路区分现金购买成本、进入市场余额的出售收入，以及提现后的现金到手金额。购买应用充值链，出售应用出售链，到手金额先应用出售链再应用提现链，费用处理在内部以 CNY 计算，API 再按官方参考汇率把结果换算成响应币种。

计算使用十进制运算，每步保留八位小数。缺少必要汇率、槽位未定义或步骤不兼容，都可能导致结果不可用。不可用不能解释为零手续费或有利可图的交易。

## API 提供什么

每条 `/prices` 报价都以 `buy_amount`、`sale_amount`、`payout_amount` 提供这三档金额，它们按该市场的官方费率链计算，并换算成响应币种：请求的 `currency`，否则为账号本位币，再否则为美元。`null` 表示该金额不可用，例如费率未知、该用途不受支持，或当前价格的金额尚未算出。CSCP 使用经费用调整的数据，见[估值](/docs/concepts/valuation)。目前没有利润筛选接口。

自己的费率链不会改变这些金额。要让某个金额经过自己的链计算，请按[用 API 自定义费率](/docs/guides/customize-fees)中的方法试算。

自行比较时，应明确手续费、汇率、可用数量与数据年龄等假设。价格差额不等于实际利润。

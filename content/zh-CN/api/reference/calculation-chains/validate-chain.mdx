## 操作

`POST /calculation-chains/validate`

## 行为

检查一条内联、完全展开的计算链是否存在结构问题，不保存也不执行任何内容。

- 报告 `error` 级问题（例如某步骤期望的货币与金额当前所用货币不同，或 `fixed` 换算缺少汇率）和 `warning` 级问题（例如空计算链或只有一个成员的组）。
- 不带 `start_currency` 时，会从计算链自身的起始货币开始检查，与保存时完全相同：在此没有 `error` 级问题的计算链即可保存。
- 始终返回 200 和问题列表；列表为空表示计算链没有问题。请求体格式错误时返回 422，并给出确切的字段路径，例如 `calculation_chain.steps[0].to.usd_rate`。
- 不会查询请求体中的算子 ID 和货币 ID。

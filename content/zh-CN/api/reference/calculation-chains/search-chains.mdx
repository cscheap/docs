## 操作

`GET /calculation-chains/search`

## 行为

查找可通过绑定或 Fork 来复用的计算链。

- 列出你能看到的所有未弃用计算链：你自己的、官方的以及其他用户共享的。`owner`（`mine`、`official` 或 `public`）和 `search`（名称的子串，不区分大小写）用于缩小范围。
- `website` 和 `purpose` 只保留在该市场或该用途上被某个绑定使用的计算链。
- 默认按 `ref_count` 排序，使用最多的在前，除非 `sort` 另有指定；带 `page`（以及 `page_size`，最多 100）时返回一页及 `total`。
- 每条记录带有一个可读的 `formula`：名义金额 100 流经该计算链的过程；对不固定任何货币的计算链，则是其各步骤作用于符号输入 `x` 的算式（例如 `x × 0.975`）。完整的计算链可通过 `GET /calculation-chains/{calculation_chain_id}` 获取。

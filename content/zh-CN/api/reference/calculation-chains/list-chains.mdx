## 操作

`GET /calculation-chains`

## 行为

返回你拥有的计算链，每条都取其当前修订并完整展开步骤，按 ID 排序。计算链是由费用算子、换币算子和换币算子组组成的有序列表，用于把价格换算为扣除市场手续费并完成货币换算后的金额。

- 已弃用的计算链默认不返回，除非传入 `include_deprecated=true`。
- 其他计算链可通过 `GET /calculation-chains/search` 查找；各市场所适用的计算链由 `GET /fee-workspace` 和 `GET /website-calculation-chain-bindings` 给出。
- 列表不分页。

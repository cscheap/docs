## 操作

`GET /prices`

## 行为

按 Steam market hash name 返回单个饰品在各市场的当前报价。

- 每个市场的每个方向最多一条报价，先按 `market_code`、再按 `side` 排序。当多个来源报告同一市场时，仍在售的报价优先于已下架的报价，其次直接取自该市场的数据优先于聚合平台的数据，再次以最近确认的报价（`fresh_at`）为准。
- 只有当某市场的所有来源都已下架该饰品时，才返回该市场的下架报价（`delisted_at` 有值、`quantity` 为 `0`，保留最后已知的价格）。
- 市场数据足够的饰品还会多一条 `side` 为 `mid` 的 `CSCP` 报价：cs.cheap 估值，即各市场在售挂单与求购订单的人民币加权共识，每天更新一次。其 `valuation` 对象给出置信度（`credibility`、`uncertainty`）和两侧共识价；其他报价的 `valuation` 均为 `null`。它是估值，不是可成交的报价。
- 可用 `markets`（逗号分隔的市场代码；`CSCP` 选取估值）和 `side`（`ask`、`bid`、`mid` 或 `all`）缩小结果范围。
- `market_hash_name` 必须完全匹配，包括大小写。
- 价格为十进制字符串，使用各市场自身的货币（`market_currency_code`），不做任何换算。
- `404` 表示该饰品在此 `app_id` 下没有任何报价。如果饰品的报价全部被 `markets` 或 `side` 过滤掉，则返回 `200`，`markets` 列表为空。

> [!note]
> 此端点按请求计费。失败的请求（包括 `404`）从不扣费；`meta.credit` 会报告本次费用和你的预估剩余余额。

## 操作

`GET /prices/export`

## 行为

以单个文件下载某款游戏所有有价格的饰品的报价，用于批量同步。`side` 默认为 `ask`；`side=mid` 只导出每个有估值饰品的 `CSCP` 估值，文件小得多。

- 响应体就是导出文档本身（`app_id`、`side`、`generated_at`、`items`），经 gzip 压缩（`Content-Encoding: gzip`），不是常规信封。请求 ID 与计费字段改为响应头：`X-Request-ID`、`X-Billable`，计费的响应另有 `X-Credit-Cost` 与 `X-Credit-Remaining`。
- `items` 列出在所请求方向上至少有一条报价的所有饰品，按 market hash name 排序；每个饰品的报价遵循与 `GET /prices` 相同的规则。
- 文件是服务器每隔几分钟重建一次的快照；`generated_at`（也即 `X-Export-Generated-At` 头）给出构建时间。两次重建之间的请求收到同一份文件。
- 把收到的 `ETag` 以 `If-None-Match` 原样发回：快照未变时响应为 `304 Not Modified` 且无响应体，`304` 永不计费。
- 不支持 `Range` 请求；总是发送整个文件。不支持分页，也不支持按市场过滤。
- `503 dependency_unavailable` 表示首份快照尚未建成；一分钟后重试。

> [!warning]
> 每个 `200` 都会计费，即使文件没有变化。带 `If-None-Match` 轮询，只在有新内容时才付费。

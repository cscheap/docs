## 操作

`PUT /convert-operators/{op_id}`

## 行为

只修改你发送的字段，其余保持不变。新的 `name`、`mode` 或 `rate` 会保存为新的修订；单独修改 `is_searchable` 只改变共享状态。只有所有者可以更新换币算子。

- `expected_sequence`（你上次读到的 `sequence`）：如果记录此后有变化，更新会以 409 被拒绝。
- 货币对是固定的：发送 `from_currency_id` 或 `to_currency_id` 会返回 422。如需不同的货币对，请新建一个换币算子。
- `fixed` 换币算子必须始终具有正数 `rate`：将 `mode` 设为 `fixed` 却未提供汇率，或移除 `fixed` 换币算子的汇率，都会返回 422。
- 404：不存在或对你不可见。409：对你可见但不归你所有；请 Fork 一份以获得可编辑的副本。

> [!warning]
> 改动会立即作用于所有使用该换币算子的计算链和换币算子组；如果你已共享它，也包括其他用户的。

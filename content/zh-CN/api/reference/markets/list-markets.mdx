## 操作

`GET /websites`

## 行为

返回本 API 覆盖的市场目录，例如 Steam 社区市场和第三方饰品市场。每条记录的 `code` 是其他接受市场参数的端点所使用的标识符。

- 结果按 `code` 排序。
- 已不再支持的市场默认隐藏，除非传入 `include_deprecated=true`；此时它们会带 `is_deprecated: true` 出现。

> [!note]
> 该目录由平台维护，通过 API 只能读取。

## 操作

`GET /websites/{code}/fee-schedule`

## 行为

返回平台当前为某个市场发布的费率，每种用途一个槽位：`deposit`、`sale` 和 `withdraw`。

- 每个已发布的槽位都带有完全展开的官方计算链：包含每个费用算子、换币算子和换币算子组及其数值与货币，因此一次请求就足以复现平台的计算。
- 如果槽位的计算链 `id` 为 `0`，则明确表示免费：平台不对该用途收取任何费用，且该计算链没有步骤。
- 如果平台尚未为某种用途发布官方计算链，对应槽位为 `null`：费用未知，或该市场不提供此用途。`null` 绝不表示免费。
- 每条计算链都会注明其 `start_currency`：价格必须采用该货币，计算链才适用（`null`：任意货币）。
- 不包含归属和管理类字段。

`404` 表示没有使用该代码的市场。

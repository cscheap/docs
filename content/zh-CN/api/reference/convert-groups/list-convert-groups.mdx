## 操作

`GET /convert-operator-groups`

## 行为

返回你可以在计算链中使用的换币算子组。一个组包含多个针对同一货币对的换币算子，并按其 `rule`（`min`、`max` 或 `avg`）选出一个结果，例如始终采用可用的最优汇率，或取多家交易所报价的平均值。

- 不带 `owner` 时，列表包含你能看到的全部组：你自己的、官方的以及其他用户共享的。`owner`（`mine`、`official` 或 `public`）用于缩小范围。
- `search` 按名称的子串过滤（不区分大小写）；`sort` 按 `name`（默认，官方记录在前）、`ref_count` 或 `updated_at` 排序。
- 不带 `page` 时返回完整列表；带 `page`（以及 `page_size`，最多 100）时返回一页及 `total`。每个组都完整内嵌其成员。

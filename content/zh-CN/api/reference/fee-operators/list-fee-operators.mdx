## 操作

`GET /fee-operators`

## 行为

返回你可以在计算链中使用的费用算子。费用算子是作用于当前金额的一个算术步骤（按固定的 `value` 执行 `add`、`sub`、`mul` 或 `div`）；`add` 和 `sub` 带有其金额的 `currency_code`。

- 不带 `owner` 时，列表包含你能看到的全部费用算子：你自己的、官方的以及其他用户共享的。`owner`（`mine`、`official` 或 `public`）用于缩小范围。
- `search` 按名称的子串过滤（不区分大小写）；`sort` 按 `name`（默认，官方记录在前）、`ref_count` 或 `updated_at` 排序。
- 不带 `page` 时返回完整列表；带 `page`（以及 `page_size`，最多 100）时返回一页及 `total`。

已删除的费用算子永远不会返回。

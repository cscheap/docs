## 操作

`POST /fee-operators`

## 行为

创建一个费用算子，并以修订 1 返回。

- 它归你所有且不是官方记录；设置 `is_searchable` 即可共享，让其他用户能够找到、引用和 Fork 它。
- `value` 是最多 12 位小数的精确小数；请以字符串形式发送（例如 `"0.975"`），以避免浮点舍入误差。`div` 算子的值不能为零（422）。
- `add` 和 `sub` 加上或减去一个固定金额，因此必须提供该金额的 `currency_code`；计算链只能在金额处于该货币时应用它们。`mul` 和 `div` 是比率，不接受 `currency_code`（否则返回 422）。
- `reason` 随该修订一起保存。

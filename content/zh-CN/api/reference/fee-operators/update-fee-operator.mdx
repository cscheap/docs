## 操作

`PUT /fee-operators/{op_id}`

## 行为

只修改你发送的字段，其余保持不变。新的 `name` 或 `value` 会保存为新的修订；单独修改 `is_searchable` 只改变共享状态。只有所有者可以更新费用算子。

- 把你上次读到的 `sequence` 作为 `expected_sequence` 发送：如果记录此后有变化，更新会以 409 被拒绝（`details.expected` / `details.actual`）。
- `operator` 和 `currency_code` 不可修改（422）；请改为新建一个费用算子。`div` 算子的 `value` 不能改为零（422）。
- 404：费用算子不存在或对你不可见。
- 409：它对你可见但不归你所有（官方记录或其他用户共享的记录）。请 Fork 一份以获得可编辑的副本。

> [!warning]
> 计算链按 ID 引用算子并使用其当前修订，因此改动会立即作用于所有使用该费用算子的计算链；如果你已共享它，也包括其他用户的计算链。

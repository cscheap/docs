## 操作

`GET /health`

## 行为

轻量级存活探针：只要 API 进程正在运行并处理请求，就返回 `{"status": "ok"}`。

- 它不检查数据库或其他依赖，因此这里返回 `200` 并不保证数据端点可用。如需服务健康历史，请使用 `GET /status`。
- 响应体按原样返回，不带常规的 `data` / `meta` 信封。

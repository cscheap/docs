## 操作

`GET /config`

## 行为

返回公开的非敏感服务配置。目前只有 `home_currency`，即官方计算链最终换算回的平台本位币。

- 你自己的基准货币属于账户设置，不在此返回。
- 响应带有 `Cache-Control: no-store`。


## 用量

```json
{
  "authentication": "public",
  "credit_cost": 0,
  "premium": false,
  "recommended_interval_seconds": 3600,
  "rate_limit": null,
  "unit_pricing": null
}
```

## 请求

```json
{}
```

## 响应

```json
{

    "description": "请求成功",
    "content": {

        "schema": {
```

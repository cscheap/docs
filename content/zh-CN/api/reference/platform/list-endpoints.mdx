## 操作

`GET /endpoints`

## 行为

返回本 API 每个已文档化操作的机器可读元数据，客户端无需解析 OpenAPI 文档即可规划用量。

- 每个方法和路径对应一条记录，先按路径、再按方法排序。
- 每条记录给出点数费用（`credit_cost`，按饰品数量计费的操作另有 `unit_pricing`）、是否为 `premium`、建议轮询间隔（`recommended_interval_seconds`）、`rate_limit`，以及谁可以调用（`roles`：`user`、`admin`、`machine`；为空表示无需认证）。
- 同样的数据也以每个操作的 `x-cscheap` 扩展字段出现在 OpenAPI 文档中。


## 用量

```json
{
  "authentication": "public",
  "credit_cost": 0,
  "premium": false,
  "recommended_interval_seconds": 3600,
  "rate_limit": null,
  "unit_pricing": null
}
```

## 请求

```json
{}
```

## 响应

{
  "200": {
    "description": "请求成功",

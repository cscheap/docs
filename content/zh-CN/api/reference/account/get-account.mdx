## 操作

`GET /me`

## 行为

返回 API 当前掌握的你本人账户信息：资料字段（包括 `base_currency`，即你的计算换算到的货币；`null` 表示 USD）、请求时刻有效的订阅（没有则为 `null`），以及你的点数计数。

- `credit.total` 是账户获得的全部点数，`credit.used` 是已消耗的点数，`credit.remaining` 是两者之差，最低为 `0`。
- 这些就是计费所依据的数字。控制台中的修改通常在一分钟左右同步到这里。

`404` 表示你的账户尚未同步到 API，请稍后重试。

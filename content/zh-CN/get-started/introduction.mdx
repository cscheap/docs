## cs.cheap 提供什么

cs.cheap 采集市场价格，统一饰品名称，并通过 API 提供报价。每条市场报价都有来源、币种、买卖方向与新鲜度。部分饰品还提供每日更新的 CSCP 估值。

先完成[首次请求](/docs/get-started/first-request)，再学习[读取价格数据](/docs/get-started/read-price-data)。通过 [API 概览](/docs/api/overview)选择单品、批量查询或全市场导出。

## 你的账号

在 [cs.cheap](https://cs.cheap/zh-CN) 登录。使用账号功能前，需要绑定并验证真实邮箱。设置页面提供 API 密钥，账单页面管理购买、钱包余额与订阅时段。[点数与订阅](/docs/billing/credits)决定 API 用量的计费方式。

价格是观测结果，不保证能够按该价格成交。比较金额前，请同时核对币种与时间戳。文档描述所记录的项目代码版本；代码版本本身不代表生产部署版本。

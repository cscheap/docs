После [первого запроса](/docs/get-started/first-request) посмотрите записи в `data.markets`. Каждая запись описывает одну площадку и одну сторону рынка.

## 1. Найдите сумму и валюту

Это пример части котировки, а не полный ответ и не текущая рыночная цена:

```json
{
  "market_code": "BUFF",
  "provider_code": "BUFF",
  "side": "ask",
  "market_price_amount": "100",
  "market_currency_code": "CNY",
  "quantity": 5,
  "fresh_at": "2026-11-06T00:00:00Z",
  "delisted_at": null
}
```

BUFF сообщает о предложении продажи за 100 CNY. `ask` означает предложение продажи, `bid` — заявку на покупку. `market_code` указывает площадку, `provider_code` — источник данных.

Читайте `market_price_amount` вместе с `market_currency_code`. Сумма — десятичная строка; `null` означает отсутствие значения, а не ноль.

## 2. Проверьте пригодность котировки

- Сравните `fresh_at` с допустимым возрастом данных. Старый `changed_at` сам по себе не означает, что сбор остановился.
- Если заполнен `delisted_at`, последняя цена может сохраняться, хотя предложение уже снято.
- `quantity=null` означает неизвестное количество. `is_quantity_minimum=true` задаёт нижнюю границу. Только `is_all_items_same_price=true` подтверждает одинаковую цену всех указанных единиц.

Количество 5 в примере само по себе не гарантирует покупку пяти единиц по 100 CNY.

## 3. Сравнивайте подходящие суммы

`market_price_amount` остаётся в валюте площадки даже при запросе `currency=USD`. Пересчитанные суммы используют поле `currency` ответа:

| Поле | Значение |
| --- | --- |
| `buy_amount` | Стоимость покупки с официальной комиссией пополнения |
| `sale_amount` | Поступление на баланс площадки после официальной комиссии продажи |
| `payout_amount` | Сумма после официальных комиссий продажи и вывода |

Недоступные суммы могут быть `null`. Личные настройки комиссий их не меняют. Для первой интеграции показывайте исходную цену, валюту и `fresh_at`; сравнение комиссий добавьте по необходимости.

Запись `CSCP` со стороной `mid` — дневная оценка, а не предложение. Пример первого запроса выбирает `ask`, поэтому оценки в него не входят.

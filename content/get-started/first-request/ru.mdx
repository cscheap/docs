Получите цены предложений о продаже одного предмета CS2. Нужен терминал с curl; SDK устанавливать не требуется.

## 1. Скопируйте API-ключ

1. Войдите на [cs.cheap](https://cs.cheap/ru) и откройте кабинет.
2. В настройках добавьте настоящий email, если его ещё нет, и подтвердите адрес по ссылке из письма.
3. Откройте обзор или раздел API-ключа в настройках, покажите ключ и скопируйте его. Первый ключ выдаётся автоматически, если аккаунт соответствует требованиям.
4. В разделе оплаты проверьте кредиты или действующую подписку. Без неё успешный запрос одного предмета обычно стоит один кредит. Пополнение кошелька само по себе не покупает кредиты: см. [стоимость запросов](/docs/billing/request-costs).

## 2. Отправьте запрос

Запустите команду в Bash или совместимой оболочке на компьютере или сервере. Замените `replace-with-your-key` своим ключом. Не помещайте ключ в браузерный код или публичные репозитории.

```bash
export CSCHEAP_API_KEY='replace-with-your-key'
curl --get 'https://api.cs.cheap/prices' \
  --header "Authorization: Bearer $CSCHEAP_API_KEY" \
  --data-urlencode 'app_id=730' \
  --data-urlencode 'market_hash_name=AK-47 | Redline (Field-Tested)' \
  --data-urlencode 'side=ask' \
  --write-out '\nHTTP %{http_code}\n'
```

`app_id=730` выбирает CS2. Точное английское имя включает степень износа. `side=ask` выбирает предложения о продаже. Базовый адрес — `https://api.cs.cheap`, без префикса `/v1`.

## 3. Проверьте ответ

В конце должно быть `HTTP 200`. JSON содержит массив котировок `data.markets` и идентификатор запроса `meta.request_id`. Последнюю строку HTTP добавляет curl; она не входит в JSON.

На странице [чтения результата](/docs/get-started/read-price-data) показано, где искать сумму и валюту. Значения и доступные площадки зависят от данных в момент запроса.

| Результат | Действие |
| --- | --- |
| `200`, пустой `markets` | Уберите фильтр `side` и повторите: предложений о продаже может не быть. |
| `401` | Скопируйте текущий ключ заново. Передача нового ключа в API занимает некоторое время. |
| `402` | Проверьте кредиты и текущий период подписки в разделе оплаты. |
| `404` | Проверьте точное имя и игру: у предмета нет записей цен. |
| `422` | Сверьте имена и значения параметров с командой выше. |
| `429` | Подождите время, указанное в заголовке ответа `Retry-After`. |

Другие случаи описаны в [ошибках API](/docs/api/errors). Для обращения в поддержку сохраните `meta.request_id`, но не передавайте ключ.

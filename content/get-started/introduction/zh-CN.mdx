cs.cheap 让你的应用通过一个 API 读取多个市场的饰品价格。先查询一件 CS2 饰品，再根据需要改用批量查询或全量导出。

## 查到你的第一条价格

按照[发起第一次请求](/docs/get-started/first-request)登录账号、复制 API Key，再运行一条命令。同一页会告诉你如何判断请求成功，以及出错后怎么办。你需要一个安装了 curl 的终端，以及 credits 或有效订阅。

接着[读懂查询结果](/docs/get-started/read-price-data)，找到市场、金额、币种和更新时间。详细概念可以等用到时再读。

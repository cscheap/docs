## Выберите фильтры

Передайте `market_hash_name` в `GET /prices`. Для игры, отличной от `730`, задайте `app_id`. Необязательный `markets` — коды в верхнем регистре через запятую, например `BUFF,UUYP`. `side` принимает `ask`, `bid`, `mid`, `all`; по умолчанию — `all`. Необязательный `currency` задаёт валюту пересчитанных сумм (`buy_amount`, `sale_amount`, `payout_amount`) и оценки `CSCP`: любой код официальной валюты, по умолчанию — базовая валюта аккаунта, иначе USD. Сами цены площадок остаются в их валютах.

Кодируйте имя для URL и передавайте ключ в заголовке Authorization. [Первый запрос](/docs/get-started/first-request) содержит пример, [справочник](/docs/api/reference/prices/get-price) — все ограничения.

## Пустой результат

`404` означает отсутствие любых ценовых строк предмета в игре. Если строки существуют, но все исключены фильтрами, ответ будет `200` с пустым `markets`. Такой успешный запрос оплачивается по обычным правилам. Уберите фильтры, чтобы различить случаи.

Для нескольких предметов используйте [пакетный запрос](/docs/guides/batch-prices).

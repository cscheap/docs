Сначала выполните [первый запрос](/docs/get-started/first-request). Команды ниже используют заданную там переменную `CSCHEAP_API_KEY`. Перед повторными вызовами проверьте [стоимость запросов](/docs/billing/request-costs).


## Загрузка снимка

`GET /prices/export` возвращает заранее сформированный JSON, сжатый gzip. Обёртки `data` нет; сведения об оплате находятся в заголовках. Сторона по умолчанию — `ask`; для остальных сторон и доступных оценок задайте `all`, а `mid` выгружает только оценки `CSCP` — файл гораздо меньше. `currency` (`USD`, `CNY` или `RUB`; по умолчанию — базовая валюта аккаунта, иначе USD) задаёт валюту пересчитанных сумм и котировок `CSCP`; для каждой валюты — отдельный файл со своим `ETag`.

```bash
curl --compressed --get 'https://api.cs.cheap/prices/export' \
  --header "Authorization: Bearer $CSCHEAP_API_KEY" \
  --data-urlencode 'app_id=730' --data-urlencode 'side=all' \
  --dump-header export.headers --output prices.json
```

`--compressed` распаковывает ответ. Проверьте HTTP-статус перед использованием файла. Проверяйте `generated_at` и `X-Export-Generated-At`: снимок пересобирается на сервере каждые несколько минут, а не при скачивании.

## Не загружайте неизменённые данные

Сохраните `ETag` и передайте его точное значение в `If-None-Match`. Совпадение даёт `304` без тела и списания кредитов; ограничение частоты действует. При `304` сохраняйте предыдущий файл, не заменяя его пустым выводом.

Каждый `200` оплачивается по обычным правилам выгрузки, даже если файл не изменился. `Range` игнорируется. Неизвестная игра даёт `404`; `503` означает, что первый снимок ещё не собран, — повторите через минуту.

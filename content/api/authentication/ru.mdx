## Bearer API-ключ

Передавайте `Authorization: Bearer YOUR_API_KEY`. Ключ доступен в [настройках](/docs/dashboard/api-keys) после подтверждения настоящего email. Cookie сеанса сайта не заменяет API-ключ.

Храните ключ на сервере. Не помещайте его в URL, снимки экрана, общие примеры или публичный код браузера. Публичные каталоги не требуют ключа.

## Изменение ключа

Перегенерация заменяет активный ключ; действует пятиминутный интервал между генерациями. Обновите настройки клиентов. Изменения аккаунта и ключа передаются в API асинхронно, поэтому новый ключ может заработать не сразу.

Отсутствующие или неверные данные дают `401`, недостаточные права при действительных данных — `403`. Недостаток кредитов — отдельная ошибка `402`. См. [устранение проблем входа](/docs/support/authentication).

## Адрес и форматы

Используйте `https://api.cs.cheap` без префикса версии. JSON кодируется UTF-8. Большинство успешных ответов содержит `data` и `meta`; [выгрузка](/docs/api/reference/prices/export-prices) возвращает файл.

## Выберите операцию

| Задача | Операция |
| --- | --- |
| Один предмет | `GET /prices` |
| До 1000 имён или постранично все предметы | `POST /prices/batch` |
| Полный снимок игры | `GET /prices/export` |
| Ваши кредиты и подписка | `GET /me` |
| Площадки и комиссии | `GET /websites` и связанные маршруты чтения |
| Валюты | `GET /currencies` и чтение одной валюты |
| Ваше рабочее пространство тарифов, цепочки и операторы | `GET /fee-workspace` и маршруты тарифов; см. [свои тарифы](/docs/guides/customize-fees) |
| Метаданные и состояние | `GET /config`, `/endpoints`, `/health`, `/status` |

Цены, аккаунт и тарифы требуют пользовательский ключ. Каталоги, метаданные и состояние доступны публично. Здесь описаны только анонимные и обычные пользовательские операции. Каталог самого сервиса может также перечислять операции других ролей; наличие записи не даёт права вызова.

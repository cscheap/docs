## Операция

`GET /config`

## Поведение

Возвращает публичную, не конфиденциальную конфигурацию сервиса. Сейчас это только `home_currency` — базовая валюта платформы, в которую официальные цепочки расчёта переводят свои результаты.

- Ваша собственная базовая валюта — это настройка аккаунта, здесь она не возвращается.
- Ответы отправляются с `Cache-Control: no-store`.


## Использование

```json
{
  "authentication": "public",
  "credit_cost": 0,
  "premium": false,
  "recommended_interval_seconds": 3600,
  "rate_limit": null,
  "unit_pricing": null
}
```

## Запрос

```json
{}
```

## Ответы

```json
{
  "200": {
    "description": "Успешный ответ",
    "content": {
      "application/json": {
        "schema": {
          "$ref": "#/components/schemas/Envelope_ConfigOut_"
        }
      }
    }
  }
}
```

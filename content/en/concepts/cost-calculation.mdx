## Three different amounts

The processing pipeline distinguishes the cash cost of buying, sale proceeds in a marketplace balance, and cash received after withdrawal. Buying applies the deposit chain; sale applies the sale chain; payout applies sale followed by withdrawal. Fee processing works in CNY internally; the API converts the results into the response currency with the official reference rates.

Calculations use decimal arithmetic with eight-place rounding at each step. Missing required rates, undefined slots or incompatible steps can make a result unavailable. An unavailable result must not be interpreted as a zero fee or a profitable trade.

## What the API exposes

Every `/prices` quote carries the three amounts as `buy_amount`, `sale_amount` and `payout_amount`, computed with the marketplace's official fee chains and converted into the response currency: the `currency` you request, else your account's base currency, else USD. `null` means the amount is not available, for example because the fee is unknown, the purpose is not offered or the amount is not yet computed for the current price. CSCP valuation uses fee-adjusted evidence, as described in [valuation](/docs/concepts/valuation). There is no profit-screening endpoint.

Your own fee chains do not change these amounts. To run an amount through a chain of your own, use a preview as described in [customize fees](/docs/guides/customize-fees).

If you calculate comparisons yourself, state your assumptions about fees, currency conversion, available quantity and quote age. A price difference alone is not realized profit.

## Contact channels

The website links to the [cs.cheap Telegram community](https://t.me/cscheap) and [Discord](https://discord.gg/xkVDrZfssx). Use the site's current community links if an invitation changes. The dashboard ticket page is currently a placeholder, not a working ticket submission system. No response-time guarantee is specified here.

## Make an issue reproducible

Include the operation and HTTP method, app and item name if relevant, UTC time, HTTP status, `error.code` and `X-Request-ID`. Describe expected and actual behavior and provide a minimal redacted request/response.

For billing, include an order reference through an appropriate private channel. Remove API keys, Authorization headers, email addresses, wallet secrets and other personal information from public posts. Do not paste a complete account response into a community channel.

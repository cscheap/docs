## What cs.cheap provides

cs.cheap collects marketplace prices, normalizes item names and exposes quotes through an API. A marketplace quote records a source, currency, market side and freshness. Some items also have a daily CSCP valuation.

Start with [your first request](/docs/get-started/first-request), then learn to [read price data](/docs/get-started/read-price-data). Use the [API overview](/docs/api/overview) to choose single-item, batch or full-market export access.

## Your account

Sign in at [cs.cheap](https://cs.cheap/en). Add and verify a real email address before using account features. Settings contains your API key; Billing contains purchases, wallet balance and subscription periods. [Credits and subscriptions](/docs/billing/credits) control API usage.

Prices are observations, not guaranteed executable offers. Compare currencies and timestamps before comparing amounts. Documentation describes the recorded project revisions; a code revision alone does not prove which revision a deployment is running.

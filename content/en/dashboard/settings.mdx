## Account settings

Settings contains profile, email, password, connected accounts, API key and preferences. An incomplete account sees a reduced set of controls focused on email verification and identity linking. Finish those steps to unlock the rest of the dashboard.

Use the password reset flow if you forgot an existing password. Changing a known password requires the current one; creating an initial password for a social account requires a completed, verified account. Availability follows your actual login methods.

## Preferences and limits

The base-currency preference is an account setting; it does not rewrite the native currency of `/prices` responses. Language selection supports English, Simplified Chinese and Russian.

The current self-service deletion action is restricted to incomplete accounts. Do not assume it provides a general deletion flow for every account. For an unavailable action, use [support](/docs/support/contact). Notification, mail and ticket placeholders should not be treated as completed tools.

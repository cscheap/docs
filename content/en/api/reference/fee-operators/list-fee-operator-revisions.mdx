## Operation

`GET /fee-operators/{op_id}/revisions`

## Behavior

Returns every saved revision of a fee operator you can read, newest first: its content, `reason`, `actor` (`user`, or `platform` for automated updates) and time.

A `404` means the fee operator is not visible to you.


## Usage

```json
{
  "authentication": "user-api-key",
  "credit_cost": 0,
  "premium": false,
  "recommended_interval_seconds": null,
  "rate_limit": null,
  "unit_pricing": null
}
```

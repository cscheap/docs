## Operation

`PUT /fee-operators/{op_id}`

## Behavior

Changes the fields you send and leaves the rest untouched. A new `name` or `value` is saved as a new revision; `is_searchable` alone only changes sharing. Only the owner can update a fee operator.

- Send the `sequence` you last read as `expected_sequence`: if the record changed since, the update is refused with 409 (`details.expected` / `details.actual`).
- `operator` and `currency_code` cannot be changed (422); create a new fee operator instead. A `div` operator cannot get a zero `value` (422).
- 404: the fee operator does not exist or is not visible to you.
- 409: it is visible but not yours (an official record or another user's shared record). Fork it to get an editable copy.

> [!warning]
> Calculation chains reference operators by ID and use their current revision, so the change applies immediately to every chain that uses this fee operator, including other users' chains if you have shared it.

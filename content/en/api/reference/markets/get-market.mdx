## Operation

`GET /websites/{code}`

## Behavior

Returns one marketplace by its `code`, including marketplaces that are no longer supported (check `is_deprecated`).

A `404` means no marketplace has this code.


## Usage

```json
{
  "authentication": "public",
  "credit_cost": 0,
  "premium": false,
  "recommended_interval_seconds": 300,
  "rate_limit": null,
  "unit_pricing": null
}
```

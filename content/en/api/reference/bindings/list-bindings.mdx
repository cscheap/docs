## Operation

`GET /website-calculation-chain-bindings`

## Behavior

Returns which calculation chain revision applies to a marketplace for each purpose: `deposit`, `sale` and `withdraw`.

- For each purpose, your own binding wins over the platform default; `source` says which one you got. A purpose with neither is `null`.
- Each slot names the bound `calculation_chain_revision` (its name and step count are that revision's), the slot `sequence` (yours) and whether the binding can be applied (`available`, `reason`).
- 404 if the marketplace code is unknown.

> [!note]
> The officially published fees of a marketplace are also available without authentication from `GET /websites/{code}/fee-schedule`.

## Operation

`DELETE /website-calculation-chain-bindings/{website_code}/{purpose}`

## Behavior

Removes your binding for one marketplace and purpose; for that purpose the platform default applies to you again, if there is one. Returns the slot's new `sequence`.

- `expected_sequence`: your slot's `sequence` as you last read it. `expected_official_sequence`: the platform slot's, so that you restore the official binding you saw. 409 if either changed since.
- 404 if you have no binding for that slot.
- The chain itself is not affected.

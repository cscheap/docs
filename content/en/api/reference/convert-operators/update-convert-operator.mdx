## Operation

`PUT /convert-operators/{op_id}`

## Behavior

Changes the fields you send and leaves the rest untouched. A new `name`, `mode` or `rate` is saved as a new revision; `is_searchable` alone only changes sharing. Only the owner can update a convert operator.

- `expected_sequence` (the `sequence` you last read) refuses the update with 409 if the record changed since.
- The currency pair is fixed: sending `from_currency_id` or `to_currency_id` returns 422. Create a new convert operator for a different pair.
- A `fixed` convert operator must keep a positive `rate`: setting `mode` to `fixed` without one, or removing the rate of a `fixed` one, returns 422.
- 404: not found or not visible to you. 409: visible but not yours; fork it to get an editable copy.

> [!warning]
> The change applies immediately to every calculation chain and group that uses this convert operator, including other users' if you have shared it.

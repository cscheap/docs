## Operation

`GET /currencies`

## Behavior

Returns the official currencies maintained by the platform, with their current USD exchange rates. These are the currencies the official fee schedules convert between.

- Results are ordered by `code` unless `sort` says otherwise.
- `search` narrows the list to codes containing the given text (case-insensitive).
- Without `page` the whole list is returned; with `page` (and `page_size`, at most 100) one page with the `total`.
- `usd_rate` is the value of one unit in US dollars, as a decimal string (for example `0.125` for a currency worth 1/8 USD).
- Only official currencies are listed.

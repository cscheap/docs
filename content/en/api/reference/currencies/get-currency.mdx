## Operation

`GET /currencies/{currency_id}`

## Behavior

Returns one official currency by its numeric `id`.

A `404` means no official currency has this id: the id does not exist, was deleted, or is not an official currency.


## Usage

```json
{
  "authentication": "public",
  "credit_cost": 0,
  "premium": false,
  "recommended_interval_seconds": 300,
  "rate_limit": null,
  "unit_pricing": null
}
```

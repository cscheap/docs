## Operation

`POST /calculation-chains/validate`

## Behavior

Checks an inline, fully expanded calculation chain for structural problems without saving or running anything.

- Reports `error` issues (for example a step expecting a different currency than the one the amount is in, or a `fixed` convert without a rate) and `warning` issues (for example an empty chain or a single-member group).
- Without `start_currency` the chain is checked from its own start currency, exactly as saving it does: a chain with no `error` issue here can be saved.
- Always returns 200 with the list of issues; an empty list means the chain is clean. A malformed payload returns 422 with the exact field path, such as `calculation_chain.steps[0].to.usd_rate`.
- Operator and currency IDs in the payload are not looked up.

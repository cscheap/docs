## Operation

`POST /calculation-chains/{calculation_chain_id}/deprecate`

## Behavior

Deprecates one of your calculation chains and returns it. Deprecation is final: the chain stays readable and can still be forked, but it can no longer be changed or bound, and it disappears from search and from your chain list unless you ask for deprecated chains.

- Only while no marketplace slot (yours, another user's or the platform's) is bound to it: otherwise 409 with `details.bindings` listing each slot (`owner_scope`, `website_code`, `purpose`, `revision`). Stop sharing the chain and wait for those slots to move.
- `expected_sequence` in the body refuses it with 409 if the chain changed since.
- Calling it on a chain that is already deprecated changes nothing.
- Only the owner can deprecate: 409 if the chain is visible but not yours (the built-in no-fee chain `0` included), 404 if it is not visible.

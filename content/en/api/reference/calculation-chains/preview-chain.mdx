## Operation

`POST /calculation-chains/preview`

## Behavior

Runs an amount through a calculation chain and returns the result with a step-by-step ledger. Nothing is saved.

- Pass either `calculation_chain_id` (a saved chain you can read; 404 otherwise) or an inline expanded `calculation_chain`, which wins if both are given.
- Amounts are rounded half-up to 8 decimal places after every step.
- If a step cannot compute, the response is still 200: `final` is `null`, and the failing ledger entry carries an `error`.
- With `to_home: true` the result is also converted into your account's base currency (USD unless you changed it); the chain's own `output_auto` does not change this. An API key must not send `home_currency` (422).
- 422 when your base currency is not in the official catalog; 503 when your account settings cannot be read right now.

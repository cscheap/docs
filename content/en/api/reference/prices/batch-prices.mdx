## Operation

`POST /prices/batch`

## Behavior

Returns the current quotes for a list of items in one call. Each item's quotes follow the same rules as `GET /prices`: at most one per market and side, listed quotes preferred over delisted ones, then marketplace-sourced data over aggregators, then the freshest, plus the item's `CSCP` valuation (`side` `mid`) when it has one.

- `items` has one entry per requested name, in request order.
- Unknown names are not an error: they come back with an empty `markets` list. This endpoint never returns `404`.
- Duplicate names are kept, and each occurrence gets its own entry.
- `markets` and `side` filter every item the same way.
- Unknown fields in the request body are rejected with `422`.

> [!note]
> Billed per started block of item names, counted over the full `market_hash_names` list including duplicates. The cost is checked before the lookup (`402` if your balance is too low) and charged only when the request succeeds.

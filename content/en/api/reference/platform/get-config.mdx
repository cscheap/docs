## Operation

`GET /config`

## Behavior

Returns public, non-sensitive service configuration. Currently this is only `home_currency`, the platform currency that official calculation chains convert their results back into.

- Your own base currency is an account setting and is not returned here.
- Responses are sent with `Cache-Control: no-store`.


## Usage

```json
{
  "authentication": "public",
  "credit_cost": 0,
  "premium": false,
  "recommended_interval_seconds": 3600,
  "rate_limit": null,
  "unit_pricing": null
}
```

## Operation

`GET /status`

## Behavior

Returns the service health and data-collection activity shown on the public status page: hourly health scores for the last 24 completed hours, per-component availability, price collection counts, and the geographic footprint of the collection network.

- Unlike `GET /health`, this reads recorded monitoring data; it is a history view, not a live probe of each dependency.
- Timestamps are UTC. Components or buckets with no data are empty or absent rather than zero.
- `503` means the monitoring data could not be read; partial results are never returned.

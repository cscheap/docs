## Operation

`GET /endpoints`

## Behavior

Returns machine-readable metadata for every documented operation of this API, so a client can plan its usage without parsing the OpenAPI document.

- One entry per method and path, sorted by path and then method.
- Each entry gives the credit cost (`credit_cost`, plus `unit_pricing` for operations billed by item count), whether it is `premium`, the suggested polling interval (`recommended_interval_seconds`), the `rate_limit`, and who may call it (`roles`: `user`, `admin`, `machine`; empty means no authentication is required).
- The same data appears in the OpenAPI document as the `x-cscheap` extension of each operation.


## Usage

```json
{
  "authentication": "public",
  "credit_cost": 0,
  "premium": false,
  "recommended_interval_seconds": 3600,
  "rate_limit": null,
  "unit_pricing": null
}
```

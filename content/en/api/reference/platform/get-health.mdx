## Operation

`GET /health`

## Behavior

Lightweight liveness probe: returns `{"status": "ok"}` whenever the API process is up and serving requests.

- It checks no databases or other dependencies, so a `200` here does not guarantee that data endpoints are available. Use `GET /status` for service health history.
- The body is returned as-is, without the usual `data` / `meta` envelope.

## Настройки аккаунта

Здесь находятся профиль, email, пароль, привязки, API-ключ и предпочтения. Незавершённый аккаунт видит сокращённые элементы для подтверждения email и привязки входа. Завершите эти шаги для доступа к остальному кабинету.

Если забыли пароль, используйте восстановление. Для изменения известного пароля нужен текущий; первый пароль социального аккаунта требует завершённого аккаунта с подтверждённым email. Доступность зависит от способов входа.

## Предпочтения и ограничения

Базовая валюта — валюта по умолчанию для пересчитанных сумм API и расчётов в кабинете. Цены площадок в ответах `/prices` остаются в своих валютах, а смена базовой валюты не пересчитывает кошелёк, который всегда ведётся в долларах США. Интерфейс поддерживает английский, упрощённый китайский и русский.

Самостоятельное удаление сейчас доступно только незавершённым аккаунтам. Это не универсальная процедура для всех пользователей. Для недоступного действия обратитесь в [поддержку](/docs/support/contact). В разделе «Расходы и доступность функций» перечислены Журнал сделок, Напоминания, Тарифы рынков и Почта на домене с порогом общих расходов для каждой функции. Выпущены только Тарифы рынков; остальные три пункта — лишь сведения о доступности, а не готовые инструменты. Для обращений в поддержку в кабинете есть отдельная страница заявок.

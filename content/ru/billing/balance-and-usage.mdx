## Представление аккаунта в API

Вызовите [GET /me](/docs/api/reference/account/get-account) активным ключом. `data.credit.total` — начисленные кредиты, `used` — израсходованные, `remaining=max(0, total-used)`. `data.subscription` описывает действующий период или равен null.

Это текущий снимок аккаунта в API. Покупки, ключи и профиль синхронизируются асинхронно. Деньги кошелька, начисление кредитов и использование API — разные записи; они могут обновляться не одновременно.

## Проверка расхождений

Сравнивайте один аккаунт, проверьте исполнение заказа и даты подписки, затем обновите данные после синхронизации. Не складывайте доллары кошелька с кредитами. Подсказка отдельного ответа при параллельных запросах может отличаться от последующего чтения аккаунта.

История отдельных API-запросов сейчас не предоставляется. При устойчивой проблеме сохраните ID запроса, время UTC и номер заказа. См. [проблемы оплаты](/docs/support/billing).

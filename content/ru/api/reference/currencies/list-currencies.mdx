## Операция

`GET /currencies`

## Поведение

Возвращает официальные валюты, которые ведёт платформа, с их текущими курсами к USD. Именно между этими валютами выполняются конвертации в официальных графиках комиссий.

- Результаты упорядочены по `code`, если `sort` не задаёт иное.
- `search` оставляет в списке только коды, содержащие заданный текст (без учёта регистра).
- Без `page` возвращается весь список; с `page` (и `page_size`, не более 100) — одна страница с `total`.
- `usd_rate` — стоимость одной единицы валюты в долларах США в виде десятичной строки (например, `0.125` для валюты, которая стоит 1/8 USD).
- В списке только официальные валюты.

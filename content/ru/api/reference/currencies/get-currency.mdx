## Операция

`GET /currencies/{currency_id}`

## Поведение

Возвращает одну официальную валюту по её числовому `id`.

`404` означает, что официальной валюты с таким ID нет: ID не существует, валюта удалена или не является официальной.


## Использование

```json
{
  "authentication": "public",
  "credit_cost": 0,
  "premium": false,
  "recommended_interval_seconds": 300,
  "rate_limit": null,
  "unit_pricing": null
}
```

## Запрос

```json
{
  "parameters": [
    {
      "name": "currency_id",
      "in": "path",
      "required": true,
      "schema": {
        "type": "integer",
        "description": "Числовой ID валюты (поле `id`).",
        "title": "Currency Id"
      },
      "description": "Числовой ID валюты (поле `id`)."
    }
  ]
}
```

## Операция

`PUT /me/currencies/{code}`

## Поведение

Изменяет `name`, `kind` или `usd_rate` одной из ваших собственных валют. Обновление частичное: неуказанные поля сохраняют текущие значения. Сам `code` изменить нельзя.

- `usd_rate` должен быть положительным, а `kind` — непустым (иначе `422`).
- Операторы конвертации в режиме `auto`, использующие эту валюту, начинают применять новый `usd_rate`.

`404` означает, что у вас нет действующей валюты с таким кодом. Нужна активная подписка.


## Использование

```json
{
  "authentication": "user-api-key",
  "credit_cost": 0,
  "premium": false,
  "recommended_interval_seconds": null,
  "rate_limit": null,
  "unit_pricing": null
}
```

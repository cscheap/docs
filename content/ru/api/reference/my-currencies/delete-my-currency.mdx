## Операция

`DELETE /me/currencies/{code}`

## Поведение

Удаляет одну из ваших собственных валют и возвращает её в прежнем виде, с `is_deleted`, равным `true`. Код снова можно использовать для новой валюты.

- `404`: у вас нет действующей валюты с таким кодом.
- `409`: валюту всё ещё использует один из ваших операторов конвертации (`ref_count` больше нуля). Сначала удалите или измените эти операторы.
- `403`: нет активной подписки (`subscription_required`).


## Использование

```json
{
  "authentication": "user-api-key",
```

## Операция

`GET /status`

## Поведение

Возвращает состояние сервиса и активность сбора данных, которые показаны на публичной странице статуса: почасовые оценки состояния за последние 24 завершённых часа, доступность по компонентам, количество собранных цен и географию сети сбора.

- В отличие от `GET /health`, этот эндпоинт читает сохранённые данные мониторинга: это история, а не живая проверка каждой зависимости.
- Время указано в UTC. Компоненты или интервалы без данных пусты или отсутствуют, а не равны нулю.
- `503` означает, что данные мониторинга не удалось прочитать; частичные результаты никогда не возвращаются.


## Использование

```json
{
  "authentication": "public",
  "credit_cost": 0,
  "premium": false,
  "recommended_interval_seconds": 60,
  "rate_limit": null,
  "unit_pricing": null
}
```

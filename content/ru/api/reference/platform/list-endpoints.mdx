## Операция

`GET /endpoints`

## Поведение

Возвращает машиночитаемые метаданные для каждой документированной операции этого API, чтобы клиент мог планировать использование, не разбирая документ OpenAPI.

- Одна запись на каждую пару метода и пути, отсортированы по пути, затем по методу.
- Каждая запись содержит стоимость в кредитах (`credit_cost`, а также `unit_pricing` для операций, которые тарифицируются по количеству предметов), признак `premium`, рекомендуемый интервал опроса (`recommended_interval_seconds`), `rate_limit` и кто может её вызывать (`roles`: `user`, `admin`, `machine`; пустой список означает, что аутентификация не нужна).
- Те же данные есть в документе OpenAPI в расширении `x-cscheap` каждой операции.


## Использование

```json
{
  "authentication": "public",
  "credit_cost": 0,
  "premium": false,
  "recommended_interval_seconds": 3600,
  "rate_limit": null,
  "unit_pricing": null
}
```

## Запрос

```json
{}
```

## Ответы

```json
{
  "200": {
    "description": "Успешный ответ",
    "content": {
      "application/json": {
        "schema": {
          "$ref": "#/components/schemas/Envelope_list_EndpointInfoOut__"
        }
      }
    }
  }
}
```

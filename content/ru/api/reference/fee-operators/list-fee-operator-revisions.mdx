## Операция

`GET /fee-operators/{op_id}/revisions`

## Поведение

Возвращает все сохранённые ревизии оператора комиссии, который вы можете читать, начиная с новейшей: содержимое, `reason`, `actor` (`user` или `platform` для автоматических обновлений) и время.

`404` означает, что оператор комиссии вам не виден.


## Использование

```json
{
  "authentication": "user-api-key",
  "credit_cost": 0,
  "premium": false,
  "recommended_interval_seconds": null,
  "rate_limit": null,
  "unit_pricing": null
}
```

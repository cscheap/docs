## Операция

`GET /me`

## Поведение

Возвращает то, что API сейчас знает о вашем аккаунте: поля профиля, включая `base_currency` (валюта, в которую переводятся ваши расчёты; `null` означает USD), подписку, действующую в момент запроса (`null`, если её нет), и счётчики ваших кредитов.

- `credit.total` — все кредиты, начисленные аккаунту, `credit.used` — израсходованные, а `credit.remaining` — разница, никогда не меньше `0`.
- Именно по этим значениям выполняется тарификация. Изменения, сделанные в личном кабинете, появляются здесь примерно в течение минуты.

`404` означает, что ваш аккаунт ещё не попал в API; повторите запрос чуть позже.


## Использование

```json
{
  "authentication": "user-api-key",
  "credit_cost": 0,
  "premium": false,
  "recommended_interval_seconds": 60,
  "rate_limit": null,
  "unit_pricing": null
}
```

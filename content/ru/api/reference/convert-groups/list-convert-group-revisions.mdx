## Операция

`GET /convert-operator-groups/{op_id}/revisions`

## Поведение

Возвращает все сохранённые ревизии группы, которую вы можете читать, начиная с новейшей: название, правило и ID участников, `reason`, `actor` и время.

`404` означает, что группа вам не видна.


## Использование

```json
{
  "authentication": "user-api-key",
  "credit_cost": 0,
  "premium": false,
  "recommended_interval_seconds": null,
  "rate_limit": null,
  "unit_pricing": null
}
```

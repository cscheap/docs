## Операция

`POST /convert-operator-groups`

## Поведение

Создаёт группу операторов конвертации и возвращает её как ревизию 1 с развёрнутыми участниками.

- Каждый ID в `member_convert_operator_ids` должен указывать на оператор конвертации, на который вам разрешено ссылаться: ваш собственный, официальный или открытый другим пользователем. Каждый недоступный ID перечисляется в ответе 400 в `details.missing`; повторяющийся ID возвращает 400.
- Нужен хотя бы один участник, и все участники должны конвертировать между одними и теми же двумя валютами: эта пара становится парой группы, и позже её изменить нельзя. Иначе 422, а проблемы перечислены в `details.issues`.
- Группа принадлежит вам и не является официальной; задайте `is_searchable`, чтобы открыть к ней доступ.

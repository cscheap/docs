## Операция

`GET /calculation-chains/search`

## Поведение

Находит цепочки расчёта для переиспользования — через привязку или форк.

- Перечисляет все видимые вам цепочки, не помеченные устаревшими: ваши собственные, официальные и открытые другими пользователями. `owner` (`mine`, `official` или `public`) и `search` (подстрока названия без учёта регистра) сужают список.
- `website` и `purpose` оставляют только цепочки, которые какая-либо привязка использует на этой площадке или для этого назначения.
- Упорядочено по `ref_count` (сначала самые используемые), если `sort` не задаёт иное; с `page` (и `page_size`, не более 100) — одна страница с `total`.
- Каждая запись содержит читаемую формулу `formula`: как номинальная сумма 100 проходит через цепочку, а для цепочки, которая не фиксирует валюту, — её шаги, применённые к символьному входу `x` (например, `x × 0.975`); полную цепочку получите через `GET /calculation-chains/{calculation_chain_id}`.

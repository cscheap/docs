## Операция

`POST /calculation-chains/preview`

## Поведение

Пропускает сумму через цепочку расчёта и возвращает результат с пошаговым журналом. Ничего не сохраняется.

- Передайте либо `calculation_chain_id` (сохранённая цепочка, которую вы можете читать; иначе 404), либо встроенную развёрнутую цепочку `calculation_chain` — она имеет приоритет, если указаны обе.
- После каждого шага суммы округляются до 8 знаков после запятой (половина округляется вверх).
- Если шаг не удаётся вычислить, ответ всё равно 200: `final` равен `null`, а запись журнала для неудавшегося шага содержит `error`.
- При `to_home: true` результат также переводится в базовую валюту вашего аккаунта (USD, если вы её не меняли); собственный `output_auto` цепочки на это не влияет. API-ключ не должен передавать `home_currency` (422).
- 422, если вашей базовой валюты нет в официальном каталоге; 503, если настройки вашего аккаунта сейчас не удаётся прочитать.

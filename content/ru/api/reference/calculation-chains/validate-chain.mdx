## Операция

`POST /calculation-chains/validate`

## Поведение

Проверяет переданную в запросе, полностью развёрнутую цепочку расчёта на структурные проблемы, ничего не сохраняя и не выполняя.

- Сообщает о проблемах уровня `error` (например, шаг ожидает не ту валюту, в которой находится сумма, или конвертация `fixed` без курса) и уровня `warning` (например, пустая цепочка или группа из одного участника).
- Без `start_currency` цепочка проверяется от её собственной начальной валюты — точно так же, как при сохранении: цепочку без проблем уровня `error` здесь можно сохранить.
- Всегда возвращает 200 со списком проблем; пустой список означает, что с цепочкой всё в порядке. Некорректные данные возвращают 422 с точным путём к полю, например `calculation_chain.steps[0].to.usd_rate`.
- ID операторов и валют в данных запроса не проверяются по базе.


## Использование

```json

  "authentication": "user-api-key",
  "credit_cost": 0,
  "premium": false,

  "rate_limit": null,
  "unit_pricing": null
}
```

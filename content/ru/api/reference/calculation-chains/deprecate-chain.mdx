## Операция

`POST /calculation-chains/{calculation_chain_id}/deprecate`

## Поведение

Помечает одну из ваших цепочек расчёта устаревшей и возвращает её. Это окончательно: цепочку можно по-прежнему читать и делать её форк, но больше нельзя изменить или привязать; она пропадает из поиска и не выводится в списке ваших цепочек, если вы не запросите устаревшие цепочки.

- Только пока к ней не привязан ни один слот площадки (ваш, другого пользователя или платформы): иначе 409 с `details.bindings`, где перечислен каждый слот (`owner_scope`, `website_code`, `purpose`, `revision`). Закройте доступ к цепочке и дождитесь, пока эти слоты будут перепривязаны.
- `expected_sequence` в теле запроса отклоняет вызов с 409, если цепочка с тех пор изменилась.
- Вызов для цепочки, которая уже помечена устаревшей, ничего не меняет.
- Помечать цепочку устаревшей может только владелец: 409, если цепочка видна, но не принадлежит вам (включая встроенную цепочку без комиссий `0`), 404, если она не видна.

## Операция

`DELETE /website-calculation-chain-bindings/{website_code}/{purpose}`

## Поведение

Удаляет вашу привязку для одной площадки и назначения; для этого назначения к вам снова применяется привязка платформы по умолчанию, если она есть. Возвращает новый `sequence` слота.

- `expected_sequence`: `sequence` вашего слота, как вы его последний раз прочитали. `expected_official_sequence`: `sequence` слота платформы — чтобы восстановить ту официальную привязку, которую вы видели. 409, если любой из них изменился.
- 404, если у вас нет привязки для этого слота.
- Сама цепочка не затрагивается.

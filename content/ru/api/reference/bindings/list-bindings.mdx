## Операция

`GET /website-calculation-chain-bindings`

## Поведение

Возвращает, какая ревизия цепочки расчёта применяется к площадке для каждого назначения: `deposit`, `sale` и `withdraw`.

- Для каждого назначения ваша собственная привязка имеет приоритет над привязкой платформы по умолчанию; `source` показывает, какая из них получена. Назначение без обеих привязок равно `null`.
- Каждый слот указывает привязанную `calculation_chain_revision` (название и число шагов взяты из этой ревизии), `sequence` слота (ваш) и можно ли применить привязку (`available`, `reason`).
- 404, если код площадки неизвестен.

> [!note]
> Официально опубликованные комиссии площадки также доступны без аутентификации через `GET /websites/{code}/fee-schedule`.

## Операция

`GET /websites/{code}`

## Поведение

Возвращает одну площадку по её `code`, в том числе площадку, которая больше не поддерживается (проверяйте `is_deprecated`).

`404` означает, что площадки с таким кодом нет.


## Использование

```json
{
  "authentication": "public",
  "credit_cost": 0,
  "premium": false,
  "recommended_interval_seconds": 300,
  "rate_limit": null,
  "unit_pricing": null
}
```

## Запрос

```json
{
  "parameters": [
    {
      "name": "code",
      "in": "path",
      "required": true,
      "schema": {
        "type": "string",
        "description": "Код площадки из списка `GET /websites`.",
        "title": "Code"
      },
      "description": "Код площадки из списка `GET /websites`."
    }
  ]
}
```

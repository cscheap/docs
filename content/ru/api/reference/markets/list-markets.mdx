## Операция

`GET /websites`

## Поведение

Возвращает каталог площадок, которые охватывает API, например Steam Community Market и сторонние площадки скинов. `code` каждой записи — это идентификатор, который используют другие эндпоинты, принимающие площадку.

- Результаты упорядочены по `code`.
- Площадки, которые больше не поддерживаются, скрыты, если не указано `include_deprecated=true`; тогда они выводятся с `is_deprecated: true`.

> [!note]
> Каталог ведёт платформа; через API он доступен только для чтения.


## Использование

```json
{
  "authentication": "public",
  "credit_cost": 0,
  "premium": false,
  "recommended_interval_seconds": 300,
  "rate_limit": null,
  "unit_pricing": null
}
```

## Запрос

```json
{
  "parameters": [
    {
      "name": "include_deprecated",
      "in": "query",
      "required": false,
      "schema": {
        "type": "boolean",
        "description": "Также вернуть площадки, которые больше не поддерживаются (`is_deprecated: true`).",
        "default": false,
        "title": "Include Deprecated"
      },
      "description": "Также вернуть площадки, которые больше не поддерживаются (`is_deprecated: true`)."
    }
  ]
}
```

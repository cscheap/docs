## Операция

`GET /websites/{code}/fee-schedule`

## Поведение

Возвращает комиссии, которые платформа сейчас публикует для одной площадки, по одному слоту на каждое назначение: `deposit`, `sale` и `withdraw`.

- Каждый опубликованный слот содержит полностью развёрнутую официальную цепочку расчёта: все операторы комиссий, операторы конвертации и группы операторов конвертации с их значениями и валютами, поэтому одного запроса достаточно, чтобы воспроизвести расчёт платформы.
- Слот, цепочка которого имеет `id` `0`, явно бесплатен: платформа ничего не взимает за это назначение, а у цепочки нет шагов.
- Слот равен `null`, если у платформы нет опубликованной официальной цепочки расчёта для этого назначения: комиссия неизвестна или площадка его не предлагает. `null` никогда не означает «бесплатно».
- Каждая цепочка указывает свою `start_currency`: валюту, в которой должна быть цена, чтобы цепочка применялась (`null`: любая валюта).
- Поля владения и управления не включаются.

`404` означает, что площадки с таким кодом нет.

{
  "authentication": "public",
  "credit_cost": 0,
  "premium": false,

  "rate_limit": null,
  "unit_pricing": null
}

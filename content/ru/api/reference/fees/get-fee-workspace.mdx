## Операция

`GET /fee-workspace`

## Поведение

Возвращает одним запросом всё, что показывает рабочая область комиссий: вашу домашнюю валюту, можете ли вы сохранять, доступные вам валюты и каждую площадку с цепочкой расчёта, применяемой для каждого назначения.

- Каждый слот содержит привязку платформы (`official`) и вашу (`personal`), каждая развёрнута в привязанной ревизии, и `applied`: `personal`, пока у вас есть своя привязка и активная подписка, иначе `official`, если она есть у платформы, иначе `none`.
- Привязка, которую нельзя применить (`available: false`, `reason` `deprecated` или `missing`), сообщается как есть; она никогда незаметно не заменяется привязкой платформы.
- `official_sequence` и `personal_sequence` — значения `sequence` слотов, которые нужно передавать при их изменении.
- Без активной подписки `personal_writable` равно `false`; чтение остаётся доступным.

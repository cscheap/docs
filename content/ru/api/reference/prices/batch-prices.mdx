## Операция

`POST /prices/batch`

## Поведение

Возвращает текущие котировки списка предметов за один вызов. Котировки каждого предмета подчиняются тем же правилам, что и в `GET /prices`: не больше одной на каждую пару площадки и стороны рынка, выставленные котировки предпочтительнее снятых, затем данные с самой площадки предпочтительнее данных агрегаторов, затем выбирается самая свежая; если у предмета есть оценка `CSCP` (`side` `mid`), она добавляется.

- `items` содержит по одной записи на каждое запрошенное название в порядке запроса.
- Неизвестные названия не считаются ошибкой: для них возвращается пустой список `markets`. Этот эндпоинт никогда не возвращает `404`.
- Повторяющиеся названия сохраняются, и каждое вхождение получает собственную запись.
- `markets` и `side` фильтруют все предметы одинаково.
- Неизвестные поля в теле запроса отклоняются с `422`.

> [!note]
> Оплата взимается за каждый начатый блок названий предметов; считается весь список `market_hash_names`, включая повторы. Стоимость проверяется до поиска (`402`, если баланса не хватает), а списывается только при успешном запросе.

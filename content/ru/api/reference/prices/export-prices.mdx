## Операция

`GET /prices/export`

## Поведение

Скачивает котировки всех предметов одной игры, у которых есть цены, одним файлом — для массовой синхронизации. По умолчанию `side` равен `ask`; `side=mid` выгружает только оценку `CSCP` каждого оценённого предмета — гораздо меньший файл.

- Тело ответа — сам документ выгрузки (`app_id`, `side`, `generated_at`, `items`), сжатый gzip (`Content-Encoding: gzip`), а не обычный конверт. Идентификатор запроса и поля биллинга передаются в заголовках: `X-Request-ID`, `X-Billable`, а для оплаченного ответа ещё `X-Credit-Cost` и `X-Credit-Remaining`.
- `items` перечисляет все предметы, у которых есть хотя бы одна котировка на запрошенной стороне рынка, в порядке market hash name; котировки каждого предмета подчиняются тем же правилам, что и в `GET /prices`.
- Файл — снимок, который сервер пересобирает раз в несколько минут; `generated_at` (он же заголовок `X-Export-Generated-At`) показывает когда. Запросы между пересборками получают один и тот же файл.
- Отправляйте полученный `ETag` обратно в `If-None-Match`: пока снимок не изменился, ответом будет `304 Not Modified` без тела, и `304` никогда не оплачивается.
- Запросы `Range` не поддерживаются; файл всегда отдаётся целиком. Пагинации и фильтра по площадкам нет.
- `503 dependency_unavailable` означает, что первый снимок ещё не собран; повторите через минуту.

> [!warning]
> Каждый `200` оплачивается, даже если файл не изменился. Опрашивайте с `If-None-Match` — и платите только когда есть что-то новое.

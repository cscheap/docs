## Операция

`GET /convert-operators/{op_id}`

## Поведение

Возвращает один оператор конвертации по ID со встроенными данными обеих валют.

Вы можете читать свои собственные операторы конвертации, официальные и открытые другими пользователями. Во всех остальных случаях возвращается 404 — точно так же, как если бы ID не существовал.


## Использование

```json
{
  "authentication": "user-api-key",
  "credit_cost": 0,
  "premium": false,
  "recommended_interval_seconds": null,
  "rate_limit": null,
  "unit_pricing": null
}
```

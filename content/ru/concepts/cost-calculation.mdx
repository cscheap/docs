## Три разных суммы

Обработка различает денежную стоимость покупки, выручку на балансе площадки и деньги после вывода. Для покупки применяется цепочка пополнения, для продажи — продажи, для выплаты — продажи и затем вывода. Обработка комиссий внутри ведётся в CNY; API пересчитывает результаты в валюту ответа по официальным справочным курсам.

Используется десятичная арифметика с округлением до восьми знаков на каждом шаге. Недостающий курс, неопределённый слот или несовместимый шаг делают результат недоступным. Это не означает нулевую комиссию или прибыльную сделку.

## Что доступно в API

Каждая котировка `/prices` содержит эти три суммы — `buy_amount`, `sale_amount` и `payout_amount`, рассчитанные по официальным цепочкам комиссий площадки и пересчитанные в валюту ответа: запрошенную в `currency`, иначе базовую валюту аккаунта, иначе USD. `null` означает, что сумма недоступна: например, комиссия неизвестна, назначение не поддерживается или сумма для текущей цены ещё не рассчитана. CSCP использует данные с учётом комиссий: см. [оценку](/docs/concepts/valuation). Интерфейса поиска прибыли нет.

Свои цепочки комиссий эти суммы не меняют. Чтобы прогнать сумму через свою цепочку, используйте предварительный расчёт, как описано в разделе [свои тарифы через API](/docs/guides/customize-fees).

В собственных сравнениях явно указывайте комиссии, курсы, количество и возраст котировок. Разница цен сама по себе не является полученной прибылью.

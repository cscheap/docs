## Какую метку времени использовать

`changed_at` — последнее изменение цены или количества, `observed_at` — отдельное наблюдение, если оно записано, `delisted_at` — снятие. В API используется RFC 3339 UTC.

`fresh_at` учитывает изменение, отдельное наблюдение и завершённый цикл сбора. Оно может обновиться при неизменной цене. Проверяйте возраст по нему: старое `changed_at` само по себе не означает остановку сбора.

## Собственная политика свежести

Выберите допустимый возраст для своего приложения. Интервалы различаются, сбои задерживают данные; API не удаляет автоматически все старые котировки. У CSCP `fresh_at` — время расчёта, `valuation_date` — дата оценки. Это не превращает дневные исходные данные в текущие цены.

В выгрузке дополнительно проверяйте возраст снимка по `generated_at`. См. [выгрузку цен](/docs/guides/export-prices).

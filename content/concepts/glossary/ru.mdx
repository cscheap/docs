## Термины

| Термин | Значение |
| --- | --- |
| Предмет | Игра и каноническое рыночное имя, не конкретный лот. |
| Площадка | Торговая площадка, к которой относится котировка. |
| Поставщик | Источник собранной котировки. |
| Ask / bid | Лот на продажу / заявка на покупку. |
| Mid / CSCP | Ежедневная расчётная оценка, не предложение для сделки. |
| Свежесть | Возраст подтверждения по `fresh_at`. |
| Снят | Больше не выставлен; последняя цена может сохраняться. |
| Кредит | Целая единица использования API, отдельная от денег кошелька. |
| Кошелёк | Баланс USD для покупок на cs.cheap. |
| Подписка | Предоплаченный период, освобождающий обычные API-запросы от списания кредитов. |
| Снимок | Сформированная выгрузка или представление аккаунта, которое может отставать от источника. |

Подробнее: [цены](/docs/concepts/prices) и [оплата](/docs/billing/credits).

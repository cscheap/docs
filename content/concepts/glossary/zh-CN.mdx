## 术语

| 术语 | 含义 |
| --- | --- |
| 饰品 | 游戏与标准市场名称的组合，不是具体挂单。 |
| 市场 | 报价所描述的交易场所。 |
| 提供方 | 报价的采集来源。 |
| Ask / bid | 在售 / 求购。 |
| Mid / CSCP | 每日计算估值，不是可成交报价。 |
| 新鲜度 | `fresh_at` 表示的数据确认时间距今的间隔。 |
| 下架 | 已不在售，但最后价格可能继续显示。 |
| 点数 | API 使用的整数计费单位，与钱包金额分离。 |
| 钱包 | 用于 cs.cheap 站内购买的 USD 余额。 |
| 订阅 | 预付费时段，有效期内非 premium API 请求不扣点数。 |
| 快照 | 生成的导出或账号视图，可能滞后于来源。 |

具体行为见[价格含义](/docs/concepts/prices)与[计费](/docs/billing/credits)。

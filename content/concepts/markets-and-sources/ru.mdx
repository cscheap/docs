## Два разных кода

`market_code` указывает площадку, для которой приведена цена, а `provider_code` — источник данных. Совпадение кодов означает данные самой площадки; различие — данные другого поставщика. Одну площадку могут описывать несколько источников.

API возвращает не больше строки на площадку и сторону рынка. Активная котировка имеет приоритет над снятой, затем прямой источник — над агрегатором, затем сравнивается свежесть. Поэтому выбранная строка не обязательно самая новая среди всех источников.

## Проверка покрытия

Используйте [каталог площадок](/docs/api/reference/markets/list-markets) и [состояние сервиса](/docs/support/service-status). Наличие площадки в каталоге не гарантирует котировок для любого предмета, игры или стороны рынка. `CSCP` обозначает расчётную оценку, а не торговую площадку.

## Каталог сайта

[Каталог](https://cs.cheap/ru/directory) группирует ссылки на площадки и инструменты по категориям. Это справочник для просмотра, отдельный от каталога источников API. Внешний инструмент не обязательно поставляет цены. Ссылка карточки открывает соответствующий сервис; его аккаунты и правила сделок управляются самим сервисом.

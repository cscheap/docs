## Где проверять

Откройте страницу состояния сайта или вызовите [GET /status](/docs/api/reference/platform/get-status) для сводных данных. [GET /health](/docs/api/reference/platform/get-health) — более лёгкая проверка. Пользовательский ключ не нужен.

Состояние и данные сбора являются снимками. Здоровый API не гарантирует свежесть каждой площадки или предмета. Проверяйте источник и `fresh_at` котировки.

## Во время сбоя

Используйте сохранённые данные только при приемлемом возрасте, явно обозначая его. Для временных сбоев применяйте ограниченные повторы, при лимите уменьшайте опрос, для устойчивых проблем сохраняйте ID запросов.

Проценты доступности отражают периоды с данными и не являются обязательством уровня сервиса. Отсутствие сведений не означает гарантированно исправное состояние.

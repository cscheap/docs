## 本地验证后的发布补充

默认设计由直接 CMS API 改为固定 Git SHA 编译的 R2 版本包，CMS 配置/后台放 docs 单仓。见 [ADR 0003](../decisions/0003-cms-editor-and-immutable-publication.md)。

- [R2 一致性](https://developers.cloudflare.com/r2/reference/consistency/)：原生 binding 与域名缓存不同；单对象一致性不代表多对象事务。
- [R2 桶范围 token](https://developers.cloudflare.com/r2/api/tokens/)：发布器使用仅授权文档桶的 Object Read & Write。
- [Miniflare R2](https://developers.cloudflare.com/workers/testing/miniflare/storage/r2/)：本地 getR2Bucket / dispatchFetch 验证。
- [Next template](https://nextjs.org/docs/app/api-reference/file-conventions/template) 与 [React cache](https://react.dev/reference/react/cache)：导航生命周期与请求快照；完整 Next 行为还需实施测试。

本次实测固定 Tina CLI 4.0.1、tinacms 3.14.3、parser 2.3.0。保留 `id` 导致 GraphQL schema 失败，故正文使用 `docId`。本地 watcher 未通过，不能据此推断托管 CMS 故障；离线编译不依赖此 watcher。

## 发布实现补充核对

- [R2 AWS SDK v3](https://developers.cloudflare.com/r2/examples/aws/aws-sdk-js-v3/)：S3 endpoint、region auto、Access Key/Secret Key；采用实际安装的 @aws-sdk/client-s3 3.1148.0。
- [GitHub concurrency](https://docs.github.com/en/actions/how-tos/write-workflows/choose-when-workflows-run/control-workflow-concurrency)：串行发布不保证 FIFO，配合激活前 master/祖先检查。
- [Infisical GitHub OIDC](https://infisical.com/docs/documentation/platform/identities/oidc-auth/github)：短期机器身份；2026-07-15 后 subject 可能包含永久数字 ID，首次连接必须读取实际配置。
